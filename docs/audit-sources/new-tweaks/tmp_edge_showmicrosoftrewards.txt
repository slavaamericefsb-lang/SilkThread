If you enable this policy: Microsoft account users (excludes Azure AD accounts) in search, new tab page, and earn markets see the Microsoft Rewards experience in their Microsoft Edge user profile. The setting to enable Microsoft Rewards in Microsoft Edge settings is enabled and toggled on. If you disable this policy: Microsoft account users (excludes Azure AD accounts) in search, new tab page, and earn markets won't see the Microsoft Rewards experience in their Microsoft Edge user profile. The setting to enable Microsoft Rewards in Microsoft Edge settings is disabled and toggled off. If you don't configure this policy: Microsoft account users (excludes Azure AD accounts) in search, new tab page, and earn markets see the Microsoft Rewards experience in their Microsoft Edge user profile.
