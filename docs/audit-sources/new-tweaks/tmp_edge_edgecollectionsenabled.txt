Supported versions Windows: 78-152 macOS: 78-152 Android: Not supported iOS: Not supported Description Starting in Microsoft Edge version 153, this policy is obsolete because the Collections feature was removed. Lets you allow users to access the Collections feature, where they can collect, organize, share, and export content more efficiently and with Office integration. If you enable or don't configure this policy, users can access and use the Collections feature in Microsoft Edge. If you disable this policy, users can't access and use Collections in Microsoft Edge.
