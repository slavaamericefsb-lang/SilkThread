# SilkThread v1.5.0 — Плавность и контроль

Дата выпуска: 16 ноября 2026.

- Последовательное появление плиток при открытии вкладок и твиков при переключении категорий.
- Проверка встроенных профилей перед применением: выбор твиков и несовместимые параметры в начале списка с объяснением.
- Обновлённые профили без отозванных настроек; несовместимые твики исключены из применения.
- Библиотека: поиск с задержкой ввода, комбинируемые фильтры и независимая прокрутка списка и инспектора.
- Аудит каталога: 304 определения, 54 отозваны; добавлены 50 условных политик Windows с описанием ограничений.
- Обновлённый графитово-фиолетовый интерфейс, адаптивные карточки и собственные полосы прокрутки.
- Диагностика: повторное использование снимка оборудования и прокрутка шапки вместе с карточками.
- Восстановление и системные настройки: явные ошибки чтения, предпросмотр изменений и журнал отката.

Проверка: 357 автоматических тестов. Реальные системные твики при проверке интерфейса не применялись. Совместимость отдельных политик зависит от редакции и сборки Windows; прирост FPS не гарантируется.

## Установка и обновление

- **SilkThread_Setup.exe** — автономный установщик для Windows x64.
- **SilkThread_Patch.zip** — полный архив файлов приложения для встроенного обновления, включая зависимости для перехода с 1.2.0.
- **SHA256SUMS.txt** — контрольные суммы установщика и архива.
- **version.json** — манифест автообновления.

Перед применением твиков проверьте список и причины несовместимости. Рекомендуется создать точку восстановления.
